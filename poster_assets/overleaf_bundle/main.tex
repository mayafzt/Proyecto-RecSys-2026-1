\begin{alertblock}{Research Question}
How competitive is a local, reproducible Two-Stage APC system against stronger alternatives when including beyond-accuracy metrics?
\end{alertblock}

\begin{block}{Data and Protocol}
\begin{itemize}
  \item Spotify playlists (Kaggle), deterministic hash sampling.
  \item Main run: 30\% sample, 63,851 playlists.
  \item Sensitivity run: 20\% sample.
  \item Split: leave-last-out, minimum 3 tracks.
\end{itemize}
\end{block}

\begin{block}{Method}
\textbf{Two-Stage Hybrid}
\begin{enumerate}
  \item Co-occurrence retrieval (item-item neighbors).
  \item Hybrid reranking (cooc + popularity + artist + playlist-name).
\end{enumerate}

\textbf{Comparators}
\begin{itemize}
  \item Sequential Markov
  \item Collaborative ItemKNN
  \item Random / Most Popular / Playlist Name Popular
\end{itemize}
\end{block}

\begin{block}{Key Findings}
\begin{itemize}
  \item Sequential Markov leads ranking quality (MAP/nDCG).
  \item Two-Stage Hybrid is competitive in HitRate@10 and clearly stronger in catalog coverage.
  \item Co-occurrence is the dominant signal (largest ablation drop).
  \item Performance is strong on short/medium + head and weak on long-tail contexts.
\end{itemize}
\end{block}

\begin{exampleblock}{Conclusions}
\begin{enumerate}
  \item Two-Stage is a robust local baseline for APC.
  \item Strong baselines are essential for fair evaluation.
  \item Beyond-accuracy metrics expose deployment trade-offs.
\end{enumerate}
\end{exampleblock}
