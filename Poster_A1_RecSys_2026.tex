\begin{block}{Problem and Goal}
Given a playlist context, recommend $k=10$ next tracks (APC).

Main constraints:
\begin{itemize}
  \item Local and reproducible pipeline over Spotify playlists.
  \item Stronger comparisons than simple baselines.
  \item Include beyond-accuracy metrics and user-level examples.
\end{itemize}
\end{block}

\begin{block}{Data and Evaluation Protocol}
\begin{itemize}
  \item Dataset: Spotify playlists (Kaggle), sampled with deterministic hash.
  \item Main run: 30\% sample, 63,851 playlists evaluated.
  \item Split: leave-last-out per playlist (minimum 3 tracks).
  \item Metrics:
  \begin{itemize}
    \item Accuracy: HitRate@10, Precision@10, MAP@10, nDCG@10.
    \item Beyond-accuracy: ILD@10, Novelty@10, CatalogCoverage@10.
  \end{itemize}
\end{itemize}
\end{block}

\begin{block}{Methods}
\textbf{Main model: Two-Stage Hybrid}
\begin{enumerate}
  \item Retrieval: item-item co-occurrence neighbors (cosine normalized).
  \item Reranking: weighted fusion of cooc, popularity, artist match, playlist-name tokens.
\end{enumerate}

\textbf{Comparators}
\begin{itemize}
  \item Sequential Markov (first-order transitions).
  \item Collaborative ItemKNN.
  \item Random, Most Popular, Playlist Name Popular.
\end{itemize}

\textbf{Ablations}
\begin{itemize}
  \item Remove each signal independently: cooc, pop, artist, name.
\end{itemize}
\end{block}

\begin{block}{Qualitative Evidence}
\textbf{Success case}\
Playlist profile: medium + head.\
Model keeps coherent soundtrack-like recommendations and recovers close target style.

\vspace{0.5em}
\textbf{Failure case}\
Playlist profile: long + tail.\
Recommendations drift to nearby electronic subgenres, missing niche target identity.

\vspace{0.5em}
This supports the quantitative long-tail gap shown in segment analysis.
\end{block}

\begin{block}{Conclusions}
\begin{enumerate}
  \item Two-Stage Hybrid is competitive in HitRate and clearly stronger in catalog coverage.
  \item Sequential Markov is a strong baseline and must be included in APC evaluations.
  \item Co-occurrence is indispensable; artist/name add meaningful incremental value.
  \item Beyond-accuracy metrics reveal practical trade-offs not visible from MAP alone.
\end{enumerate}
\end{block}

\begin{block}{Future Work}
\begin{itemize}
  \item Tail-aware reranking for niche targets.
  \item Context-adaptive weighting by playlist length/coherence.
  \item Lightweight semantic embeddings to reduce genre drift.
\end{itemize}
\end{block}
