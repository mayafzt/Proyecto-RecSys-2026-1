\begin{alertblock}{Research Question}
How competitive is a local and reproducible Two-Stage APC system against stronger alternatives when we measure both ranking quality and beyond-accuracy behavior?
\end{alertblock}

\begin{block}{Dataset and Protocol}
\begin{itemize}
  \item Spotify playlists dataset (Kaggle), deterministic hash sampling.
  \item Main run: 30\% sample, 63,851 playlists evaluated.
  \item Sensitivity run: 20\% sample.
  \item Split: leave-last-out, minimum 3 tracks per playlist.
\end{itemize}
\end{block}

\begin{block}{Method Overview}
\textbf{Two-Stage Hybrid}
\begin{enumerate}
  \item Retrieval: item-item co-occurrence neighbors (cosine normalized).
  \item Reranking: weighted fusion of cooc, popularity, artist-match, playlist-name tokens.
\end{enumerate}

\vspace{0.3em}
\textbf{Compared models}
\begin{itemize}
  \item Sequential Markov (first-order transitions)
  \item Collaborative ItemKNN
  \item Random, Most Popular, Playlist Name Popular
\end{itemize}
\end{block}

\begin{block}{Qualitative Examples}
\textbf{Success case (medium + head):}
Coherent soundtrack-like playlist where the model remains in the right musical niche and retrieves close target style.

\vspace{0.45em}
\textbf{Failure case (long + tail):}
Recommendations drift into nearby electronic subgenres, missing the specific niche identity of the target item.
\end{block}

\begin{alertblock}{What happened with LastFM?}
LastFM was evaluated as optional enrichment, but not used as core component due to API latency and reproducibility constraints at large scale.

Final protocol prioritizes fully local, stable, and repeatable experiments.
\end{alertblock}

\begin{exampleblock}{Takeaways}
\begin{enumerate}
  \item Two-Stage is competitive in Hit@10 and strong in catalog coverage.
  \item Markov is a strong APC baseline and should always be reported.
  \item Beyond-accuracy metrics reveal practical deployment trade-offs.
\end{enumerate}
\end{exampleblock}
